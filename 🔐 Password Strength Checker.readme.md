🔐 Password Strength Checker

📌 Project Description

The Password Strength Checker is a simple web-based application that evaluates the strength of a password entered by the user. It helps users create secure passwords by checking criteria like length, uppercase/lowercase letters, numbers, and special characters.

---

🚀 Features

- Checks password strength (Weak / Medium / Strong)
- Real-time validation
- User-friendly interface
- Responsive design using HTML & CSS

---

🛠️ Technologies Used

- HTML
- CSS
- JavaScript

---

▶️ How to Run the Project

1. Download or clone the repository
2. Open the project folder in Visual Studio Code
3. Right-click on "index.html"
4. Click on "Open with Live Server"
   (Make sure Live Server extension is installed)

---

📸 Output

The application displays password strength dynamically as the user types.

---

💡 Example

- Password: "abc123" → Weak
- Password: "Abc@1234" → Strong
